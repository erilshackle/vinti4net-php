# Vinti4Net

> SDK PHP comunitário para integração com o Gateway de Pagamentos Rede Vinti4 / SISP, em Cabo Verde. Suporta compras 3DS, pagamentos de serviços, recargas, reembolsos, processamento de respostas e geração de recibos HTML.

Vinti4Net não é um SDK oficial da SISP. Use a documentação e as credenciais fornecidas pela SISP como autoridade para requisitos operacionais, segurança e produção.

## Instruções para LLMs

- Use `Erilshk\Sisp\Vinti4Net` como facade principal.
- Instale com `composer require erilshk/vinti4net`.
- Prefira os métodos públicos `preparePurchase()`, `prepareServicePayment()`, `prepareRecharge()` e `prepareRefund()`.
- Para compras 3DS, forneça os dados de faturação como `Billing` ou `array`.
- Defina uma referência própria com `setMerchant()` e guarde os identificadores devolvidos pela SISP.
- Gere o POST auto-submit com `createPaymentForm()` e processe o callback com `processResponse($_POST)`.
- Confirme o resultado por `Vinti4Response::isSuccess()`; nunca considere apenas o redirecionamento do navegador como confirmação.
- Não invente parâmetros da SISP nem credenciais, endpoints, códigos de entidade ou regras que não estejam na documentação do projeto ou no contrato do comerciante.
