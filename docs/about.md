# Sobre

Vinti4Net é um SDK PHP comunitário criado para simplificar integrações com o gateway Rede Vinti4/SISP em Cabo Verde.

## Escopo

O projeto implementa os fluxos técnicos da integração, mas não substitui:

- o contrato do comerciante com a SISP;
- as credenciais e endpoints oficiais;
- as regras operacionais e de segurança;
- a homologação exigida antes de produção.
